## 🎲 Built for fun (and for me)

🚴 **N10 Escapes** - Trip planning for a small cycling club: one place for *when, where, who's
coming, what it costs and what we're riding*, judged the way cyclists judge things (bike storage,
early breakfast, the coffee stop).

🏃 **RunUrban Coach** - Coaching software for my running coaching service: the coach plans, the
athlete logs what they actually did, and both talk about it against the session it happened in.

🌧️ **Rainmaker** - A personal opportunity pipeline: leads, contacts and postings tracked from first
lead to signed offer, with "best next actions" across the funnel.

🍅 **Pomodoro Timer** - A native macOS focus timer that looks like a split-flap flip clock: focus
counts down on top, the break below, set with rotary dials and started with a big red slot-machine
button. Keeps counting in the menu bar when the window is closed.

🧊 **Urbanite Planner** (formerly Cadence) - *Plan the day · keep the rhythm.* A private Mac task
manager in Urbanite Consulting's navy and brass: a Today view, weekly progress rings, calendar,
projects by client, daily and recurring tasks, menu-bar quick add, and a focus timer whose time
rolls up into reports by client and project. No login; the data stays on the Mac, backed up daily.
Being prepared for the Mac App Store.
